# Daten- und Kontolöschung für msm-senegal

Entwickler: Saloume Seck

Wenn du die Löschung deiner Daten oder deines Benutzerkontos für die App **msm-senegal** anfordern möchtest, kannst du dies ganz einfach tun:

### Anleitung zur Datenlöschung:
1. Sende eine E-Mail von der Adresse, die mit deinem Konto verknüpft ist, an unsere Support-Adresse.
2. Verwende in der Betreffzeile: **"Löschung meiner App-Daten – msm-senegal"**.
3. Wir werden deine Anfrage innerhalb von 7 Werktagen bearbeiten und alle zugehörigen Nutzerdaten dauerhaft von unseren Servern löschen.
